# AutomatedPlantWater

Overview

This project uses an Arduino Uno R3, a capacitive soil moisture sensor, a relay module,
and a 2-6V DC submersible pump to autonomously water plants.

Hardware Used
* Arduino Uno R3
* Capacitive Soil Moisture Sensor v1.2
* Relay Module
* DC 2-6V submersible water pump
* Breadboard
* Jumper Wires
* AA batteries

Skills Demonstrated
* Embedded C++ 
* Reading anolog inputs
* Writing digital outputs
* Circuit design
* Troubleshooting and debugging

Results 

When the moisture levels in the soil drop below 50%, water is dispensed into the soil.
